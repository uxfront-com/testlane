Add a docs guide, "Use Testlane from an Agent", for AI coding agents that drive Testlane. It lists the commands to call to check out a ref, start a command, read its logs, stop it and remove the workspace, the `--json` fields to read, how to handle each exit code and which interactive commands to avoid. It ends with a block to paste into `AGENTS.md` or `CLAUDE.md`. The CLI itself is unchanged.
